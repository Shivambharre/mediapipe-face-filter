A lightweight, real-time face filtering application built using MediaPipe and OpenCV. This project detects facial landmarks and applies filters (like AR masks, glasses, or other overlays) to the detected face in real-time.
🚀 Features
Real-time Detection: Uses MediaPipe's highly optimized Face Mesh/Detection models.
Customizable Filters: Easily swap out overlays and masks.
Low Latency: Optimized for smooth performance on standard webcams.
Cross-Platform: Runs wherever Python and OpenCV are supported.
🛠 Prerequisites
Ensure you have the following installed before running the project:
Python 3.8+
pip (Python package manager)
A working webcam
